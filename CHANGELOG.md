# Changelog

## 1.1.0 - 2026-10-28

- Default API URL is now `https://app.air-core.io/api/v1/` (was `https://app.deepint.net/api/v1/`).
- New `AIRCORE_API_URL` environment variable; it takes precedence over `DEEPINT_API_URL`, which is still supported.
- Rebranded documentation and descriptions from Deep Intelligence to AIR-Core (formerly Deep Intelligence).
- No changes to package name, HTTP headers or the external source protocol.
